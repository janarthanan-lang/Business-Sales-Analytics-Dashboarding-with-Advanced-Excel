# 📊 Advanced Excel Sales Analysis Project

## 📌 Project Overview
This project focuses on analyzing Superstore sales data using **Advanced Excel techniques** to identify trends, evaluate performance, and generate actionable business insights. The outcome is an interactive dashboard that supports data-driven decision-making.

---

## 🎯 Project Objectives
- Analyze overall sales trends over time  
- Identify high-performing products, categories, and customer segments  
- Understand the impact of discounts on profitability  
- Build a dynamic dashboard with KPIs  
- Perform What-If Analysis for decision support  

---

## 📂 Dataset Description
- **Dataset:** Superstore Sales Data  
- **Rows:** 9,995  
- **Columns:** 21  
- **Key Fields:** Order ID, Customer ID, Category, Sub-Category, Sales, Quantity, Discount, Profit, Order Date, Ship Date  

---

## 🧹 Data Cleaning & Preparation
- Removed duplicate records  
- Converted Order Date & Ship Date from text to proper date format (DMY)  
- Created helper columns (Weekday, End of Month)  
- Built calculated fields:
  - **Adjusted Sales = Sales − (Sales × Discount)**  

---

## 📊 Key Analysis & Techniques Used
- Pivot Tables & Pivot Charts  
- KPI calculations (Sales, Profit, Orders, Discounts)  
- Category, Sub-Category, Segment & Ship Mode analysis  
- Year-wise order trend analysis  
- **What-If Analysis**
  - Goal Seek
  - Scenario Manager  
- **Macros & Automation** to reduce manual effort  

---

## 📈 Dashboard Features
- Interactive Excel dashboard  
- KPI cards for quick performance tracking  
- Slicers for dynamic filtering  
- Visual comparison across segments, categories, and shipping modes  

---

## 🔍 Key Insights
- Consumer segment is the top contributor with ~₹9.95 lakh in sales  
- Orders show steady yearly growth, peaking at 3312 orders in 2017  
- Binders and Paper dominate sub-category sales  
- Standard Class shipping generates the highest profit (~₹1.64 lakh)  
- Furniture category has the highest discount rate (~17%)  

---

## 💡 Business Recommendations
- Focus on Consumer segment with loyalty offers  
- Plan inventory based on increasing yearly demand  
- Bundle high-selling items with low-performing products  
- Encourage Standard Class shipping to improve profitability  
- Review Same Day delivery costs  

---

## 🧠 Conclusion
This project demonstrates how **Advanced Excel** can transform raw data into meaningful insights using data cleaning, pivot analysis, dashboards, and What-If analysis. Automation through macros improved efficiency, while insights supported strategic business decisions.
